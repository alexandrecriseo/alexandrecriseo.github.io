# Alexandre Criseo

**[alexandrecriseo.github.io](https://alexandrecriseo.github.io/)**

Products I built because I needed them, each one playable in the browser.

- [Job Search Workbench](https://alexandrecriseo.github.io/workbench/): from a noisy job feed to a deliberate application decision.
- [OuiChef](https://alexandrecriseo.github.io/ouichef/): from saved food inspiration to a meal you actually cook. Recipe photos are credited on its page.
- [Look Pilot](https://alexandrecriseo.github.io/lookpilot/): tomorrow's office outfit from the clothes you already own, shown on a person. The models used are listed on its page.

The demos run entirely in your browser on example data: the roles, companies, candidate, recipes, wardrobe and the person wearing it are made up, and nothing is sent anywhere. This repository holds the published site only; the source code of each product is private.
