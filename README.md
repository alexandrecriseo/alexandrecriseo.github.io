# Alexandre Criseo

**[alexandrecriseo.github.io](https://alexandrecriseo.github.io/)**

Three apps I built for my own life, each one playable in the browser.

- [Look Pilot](https://alexandrecriseo.github.io/lookpilot/): picks tomorrow's office outfit from my wardrobe and shows it on me. The models it uses are listed on its page.
- [Job Search Workbench](https://alexandrecriseo.github.io/workbench/): the tool I run my job search with.
- [OuiChef](https://alexandrecriseo.github.io/ouichef/): turns saved recipe videos into meals, a week plan and a shopping list. Recipe photos are credited on its page.

The demos run entirely in your browser on example data: the roles, companies, candidate, recipes, wardrobe and the person wearing it are made up, and nothing is sent anywhere. This repository holds the published site only; the source code of each product is private.
